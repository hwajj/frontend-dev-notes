# React 17 → @tanstack/react-query v4

> 작성일: 2026-08-24
> 형식: 경량
> 맥락: app-dailycare CRA·React 17 환경에 react-query 도입 시 버전 선택

## 결론

이 앱은 React 17이라 **v5(React 18+ 필수) 대신 v4**를 쓴다. `App.tsx` 최상단에 `QueryClientProvider`를 두고 `queryClient` 전역 옵션(staleTime 등)을 한곳에서 관리한다. care·companion과 같은 v4 API(`keepPreviousData` 등)를 공유한다.

## 학습 주제 · 키워드

- **React Query v4 setup**: `QueryClientProvider`, `@tanstack/react-query@4`, `peerDependencies`, `keepPreviousData`

## 이 레포 예문

```tsx
// App.tsx
<QueryClientProvider client={queryClient}>
  <BrowserRouter>...</BrowserRouter>
</QueryClientProvider>

// package.json
"@tanstack/react-query": "^4.44.0"
```
