### 크로스 포털 정산 화면 동기화 — React Query·폴링·알림

* React Query의 `invalidateQueries()`는 현재 브라우저 탭의 캐시만 갱신한다.
* 그래서 관리자 화면에서 데이터를 바꿔도 요양원 화면은 자동으로 알지 못한다.
* 다른 사용자 화면까지 동기화하려면 별도의 갱신 방법이 필요하다.
* 이 프로젝트는 WebSocket 대신 폴링(Polling)과 알림을 사용한다.
* 상세 화면에서 상대방 처리를 기다리는 상태일 때만 10초마다 데이터를 다시 조회한다.
* 알림은 30초마다 조회해서 관련 데이터가 바뀌었음을 감지한다.
* 알림을 받으면 해당 React Query 캐시를 invalidate하여 다시 조회한다.
* `staleTime`은 "캐시가 오래됐음"을 표시할 뿐, 자동 새로고침을 의미하지 않는다.
* 이 구조는 즉시 반영보다 "몇 초 안에 맞춰지는 동기화(Eventual Consistency)"를 선택한 설계다.

현재 프로젝트 흐름:

```text
관리자 또는 요양원 상태 변경
          ↓
        DB 저장
          ↓
  10초 폴링 또는 30초 알림
          ↓
   invalidateQueries()
          ↓
      데이터 재조회
          ↓
      화면 자동 갱신
```


### Node 17+에서 webpack 4(react-scripts 4)가 터지는 이유

* `react-scripts 4`는 내부적으로 webpack 4를 사용한다.
* webpack 4는 오래된 해시 알고리즘(MD4 계열)을 사용한다.
* Node 17 이상부터는 OpenSSL 3가 기본 적용되면서 일부 오래된 알고리즘이 차단되었다.
* 그래서 webpack 4가 해시를 만들다가 `ERR_OSSL_EVP_UNSUPPORTED` 오류로 종료된다.
* 문제는 프록시나 API가 아니라 개발 서버가 아예 시작되지 못하는 것이다.
* `error:0308010C`, `digital envelope routines::unsupported`가 대표적인 증상이다.
* 가장 간단한 해결책은 프로젝트 권장 버전인 Node 16을 사용하는 것이다.
* 임시 우회 방법으로 `NODE_OPTIONS=--openssl-legacy-provider`를 사용할 수 있다.
* 근본 해결은 `react-scripts 5` 또는 webpack 5 이상으로 업그레이드하는 것이다.

현재 프로젝트 기준:

```text
Node 16 + webpack 4
        ↓
      정상

Node 17+ + webpack 4
        ↓
OpenSSL 3 충돌
        ↓
ERR_OSSL_EVP_UNSUPPORTED
        ↓
개발 서버 시작 실패
```

**핵심은 "최신 Node와 오래된 webpack의 호환성 문제"이지, 프록시나 네트워크 문제가 아니라는 점이다.**


### .nvmrc와 실제 Node 버전이 다를 때

* `.nvmrc`는 프로젝트 권장 Node 버전을 적어둔 파일이다.
* 하지만 `.nvmrc`가 있다고 Node 버전이 자동으로 바뀌지는 않는다.
* 실제로 사용하는 버전은 `node -v`로 확인해야 한다.
* 팀은 Node 16을 기준으로 개발하는데, 내 PC가 Node 22면 예상치 못한 오류가 발생할 수 있다.
* 특히 `react-scripts 4`, webpack 4 프로젝트에서는 OpenSSL 관련 오류가 자주 발생한다.
* 같은 코드인데 어떤 사람은 되고 어떤 사람은 안 되는 이유가 Node 버전 차이인 경우가 많다.
* 프로젝트에 들어가면 `nvm use` 또는 `fnm use`로 `.nvmrc` 버전에 맞추는 것이 가장 안전하다.
* CI, 팀원, 내 PC의 Node 버전이 다르면 재현되지 않는 버그가 생길 수 있다.
* 문제를 조사할 때는 코드보다 먼저 `node -v`를 확인하는 습관이 중요하다.

현재 프로젝트 기준:

```text
.nvmrc = 16.20.2
       ↓
팀이 기대하는 버전

내 PC = Node 22
       ↓
webpack 4 충돌 가능
       ↓
ERR_OSSL_EVP_UNSUPPORTED
```

**핵심은 ".nvmrc는 권장 버전 메모일 뿐이고, 실제 실행 버전은 따로 확인해야 한다"는 점이다.**
