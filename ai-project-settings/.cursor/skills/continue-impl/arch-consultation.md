# 아키텍처 결정 협의 절차

> continue-impl SKILL.md의 "아키텍처 결정 협의"에서 M >= 1일 때 참조하는 절차이다.

## 1. Plan 모드 전환

`SwitchMode`로 Plan 모드로 전환한다. explanation에 협의 항목 수와 요약을 포함한다.

Plan 모드 진입 후, 각 협의 항목을 아래 형식으로 제시한다:

```
### 항목 N: {제목}
**배경**: ...
**선택지**:
- A: ...
- B: ...
```

## 2. 협의 진행

Plan 모드에서 사용자와 각 항목을 협의한다.

- 사용자가 항목을 "보류"한다고 하면:
  - 보류 항목이 기존 검증 결과 섹션(`#### 미구현`, `#### 구현 불일치`)에 있으면 progress-tracking.mdc "하단 섹션 관리 > 이동" 규칙에 따라 `#### 구현 보류`로 이동한다. 미구현 사유: "아키텍처 미확정"
  - 보류 항목이 아직 기록되지 않은 기능이면 `#### 구현 보류`에 신규 추가한다
  - 보류 항목이 이미 `#### 구현 보류`에 있으면 미구현 사유를 "아키텍처 미확정"으로 갱신한다
  - 보류 항목이 있으면 해당 대상(서버/프론트) 컬럼은 `partially-done`으로 설정한다

## 3. 복귀

모든 항목이 확정(또는 보류) 처리되면 `SwitchMode`로 Agent 모드로 복귀하여 확정된 항목만으로 구현을 진행한다.
