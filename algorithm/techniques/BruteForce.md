## 📘 **문제: 프로그래머스 Lv1. 두 개 뽑아서 더하기**

> 정수 배열 `numbers`에서 서로 다른 인덱스의 두 수를 뽑아 더한 값을 모두 구한 뒤, 중복을 제거하고 오름차순으로 반환한다.

### 💬 **입출력 예시**

| 입력                  | 출력                  |
| --------------------- | --------------------- |
| `[2, 1, 3, 4, 1]`     | `[2, 3, 4, 5, 6, 7]`  |
| `[5, 0, 2, 7]`        | `[2, 5, 7, 9, 12]`    |

### 💻 **코드 + 주석**

```js
// 두 개 뽑아서 더하기
// 서로 다른 인덱스 i, j (i < j)의 모든 합을 구하고 중복 제거 후 정렬
// (예시 문제)
// - 프로그래머스 Lv1. 두 개 뽑아서 더하기
function solution(numbers) {
  const set = new Set();

  for (let i = 0; i < numbers.length; i++) {
    for (let j = i + 1; j < numbers.length; j++) {
      set.add(numbers[i] + numbers[j]);
    }
  }

  return [...set].sort((a, b) => a - b);
}
```

**설명:**

- `i < j`로 서로 다른 인덱스만 본다. 같은 인덱스를 두 번 쓰면 안 된다.
- 합의 중복은 `Set`으로 제거한다.
- `sort()`만 쓰면 문자열 기준 정렬이 되므로 `(a, b) => a - b`가 필요하다.
- n ≤ 100이므로 O(n²) 완전탐색으로 충분하다.
