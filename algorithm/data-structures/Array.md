## 📘 **문제: 프로그래머스 Lv1. 같은 숫자는 싫어**

> 배열 `arr`에서 **연속으로** 나타나는 같은 숫자는 하나만 남기고 제거한다. 제거 후에도 원래 순서를 유지한다.

### 💬 **입출력 예시**

| 입력                    | 출력           |
| ----------------------- | -------------- |
| `[1, 1, 3, 3, 0, 1, 1]` | `[1, 3, 0, 1]` |
| `[4, 4, 4, 3, 3]`       | `[4, 3]`       |

### 💻 **코드 + 주석**

```js
// 같은 숫자는 싫어
// 직전 원소와 다를 때만 결과 배열에 push (연속 중복만 제거)
// (예시 문제)
// - 프로그래머스 Lv1. 같은 숫자는 싫어
function solution(arr) {
  const result = [];

  for (const num of arr) {
    if (result.length === 0 || result[result.length - 1] !== num) {
      result.push(num);
    }
  }

  return result;
}
```

```
//[1,1,3,3,0,1,1]
//[1,3,0,1]

arr
 ↓
1 → result []
      ↓
      [1]

1 → result 마지막 1과 비교
      ↓
      같음 → 버림

3 → result 마지막 1과 비교
      ↓
      다름 → 추가

3 → result 마지막 3과 비교
      ↓
      같음 → 버림

```

**설명:**

-
- "연속으로 같은 숫자"만 제거하면 되므로 **직전 값 하나**만 보면 된다.
- 전역 중복 제거(Set)와 다르다. `[1, 3, 0, 1]`에서 마지막 `1`은 유지된다.
- n ≤ 1,000,000이므로 O(n) 한 번 순회가 필수다.

**대안 (filter):**

```js
function solution(arr) {
  return arr.filter((num, i) => i === 0 || num !== arr[i - 1]);
}
```

## ⚡ **핵심 포인트**

| 구분       | 내용                                              |
| ---------- | ------------------------------------------------- |
| 시간복잡도 | O(n) — 배열 한 번 순회                            |
| 핵심 원칙  | 조건이 "인접(연속)"일 때 직전 원소만 비교         |
| 주의       | Set으로 전역 중복 제거와 혼동하지 않기            |
| 응용       | Run-length 압축, 연속 구간 처리, 스택 없이도 가능 |
