## Day 5: 캐시 & 리소스 힌트

### 1. 브라우저 캐시

브라우저가 이미 받은 **JS, CSS, 이미지 등의 리소스를 저장해두고 재사용**하는 것.

```text
첫 방문
브라우저 → 서버 → 리소스 다운로드 → 캐시 저장

재방문
브라우저 → 캐시 확인
          ↓
       사용 가능 → 캐시 사용
```

---

### 2. Cache-Control

서버가 브라우저에게 **캐시를 어떻게 사용할지 알려주는 응답 헤더.**

| 설정           | 의미                                      |
| -------------- | ----------------------------------------- |
| `max-age=3600` | 3600초 동안 캐시 사용                     |
| `no-cache`     | 캐시는 가능하지만 사용 전에 서버에 재검증 |
| `no-store`     | 캐시에 저장하지 않음                      |
| `immutable`    | 변경되지 않는 리소스로 간주               |

**핵심:** `no-cache` ≠ 캐시 안 함.
캐시 자체를 막는 건 `no-store`.

---

### 3. ETag + 304

캐시가 만료되었을 때 **리소스가 변경됐는지 확인하는 방법.**

```text
첫 요청
서버 → ETag: "abc"

재요청
브라우저 → If-None-Match: "abc"
서버 → 304 Not Modified
```

`304`라면:

> "리소스 안 바뀌었으니까 네가 가지고 있는 캐시 그대로 써."

변경됐다면:

```text
서버 → 200 + 새로운 리소스
```

**핵심:** 304는 실패가 아니라 **성공적인 캐시 재검증**.

### 4. 해시 파일명 + 장기 캐시

프론트 빌드 도구인 **Vite/Webpack은 빌드 시 파일명에 콘텐츠 해시를 붙여준다.**

```text
app.a1b2c3.js
```

파일 내용이 변경되면:

```text
app.d4e5f6.js
```

처럼 **파일명도 변경된다.**

그래서 JS/CSS에는 장기간 캐시를 적용할 수 있다.

```http
Cache-Control: max-age=31536000, immutable
```

브라우저는 기존 파일을 오래 캐시하지만, 배포 후 파일명이 바뀌면 새로운 URL이므로 새 파일을 다운로드한다.

**역할 구분**

```text
Vite / Webpack
→ 해시가 붙은 파일 생성

Nginx / CDN / 서버
→ Cache-Control 설정

브라우저
→ 캐시 정책에 따라 파일 재사용
```

**핵심:**

> **파일명은 빌드 도구가 관리하고, 캐시 정책은 서버/CDN이 관리한다.**

### 5. preload / prefetch

**preload**

> 현재 페이지에서 **곧 필요한 리소스**를 우선적으로 가져옴.

**prefetch**

> 다음 페이지에서 필요할 것 같은 리소스를 **미리 가져옴.**

```text
preload  → 지금 필요
prefetch → 나중에 필요할 수도
```

## 면접에서 이것만 말할 수 있으면 됨

**Q. 브라우저 캐시는 왜 사용하나요?**

> 이미 다운로드한 리소스를 재사용해서 네트워크 요청과 다운로드 비용을 줄이고 페이지 로딩을 빠르게 하기 위해 사용합니다.

**Q. `no-cache`와 `no-store` 차이는?**

> `no-cache`는 저장은 가능하지만 사용 전에 서버 재검증이 필요하고, `no-store`는 캐시에 저장하지 않습니다.

**Q. ETag와 304는?**

> ETag로 리소스의 버전을 식별하고, 브라우저가 `If-None-Match`로 재검증했을 때 변경되지 않았다면 서버가 304를 반환해 기존 캐시를 사용하게 합니다.

**Q. 프론트에서 해시 파일명을 사용하는 이유는?**

> JS/CSS 파일명에 콘텐츠 해시를 넣으면 파일 내용이 변경될 때 URL도 바뀐다. 따라서 기존 파일은 장기간 캐시하고, 새 버전은 새로운 URL로 받아올 수 있다.
