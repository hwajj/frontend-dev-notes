# Docker & CI/CD

## 키워드

- **컨테이너 / 이미지** — 실행 환경을 통째로 패키징. "내 PC에선 되는데" 제거.
- **Dockerfile** — 이미지 빌드 레시피. 레이어 캐시.
- **멀티 스테이지 빌드** — 빌드 산출물만 최종 이미지에 담아 경량화.
- **CI/CD** — 빌드·테스트·배포 자동화(GitHub Actions 등).
- **환경 분리** — dev/staging/prod, 시크릿 관리.

## 면접 포인트

- **Q. Docker가 환경 드리프트(10주차)를 어떻게 없애나?**
  → OS·런타임·의존성을 이미지에 고정해 어디서 실행해도 동일. Node 버전 충돌 같은 문제를 근본 차단.
- **Q. 멀티 스테이지 빌드의 이점은?**
  → 빌드 도구는 빌드 단계에만 두고 최종 이미지엔 산출물만 → 이미지 경량·보안 표면 축소.
- **Q. CI/CD 파이프라인의 기본 단계는?**
  → lint/test → build → (스테이징 배포/승인) → prod 배포. 실패 시 이전 버전 롤백.

## 목표

- 컨테이너/이미지 개념과 Dockerfile 기본을 안다.
- 멀티 스테이지 빌드로 이미지를 경량화한다.
- CI/CD 파이프라인 단계를 설계할 수 있다.
