# Day 15: 비동기 & 이벤트 루프

## 키워드

- **Call Stack** — 함수 호출이 쌓이는 실행 스택. JS는 싱글 스레드라 스택이 하나뿐이다.
- **Event Loop** — 콜 스택이 비면 큐에서 콜백을 꺼내 스택으로 올리는 반복 루프.
- **Macrotask** — `setTimeout`, `setInterval`, I/O 콜백 등이 들어가는 태스크 큐.
- **Microtask** — Promise 콜백(`.then`), `queueMicrotask`가 들어가는 큐. **매크로태스크보다 먼저** 비워진다.
- **Promise** — 비동기 작업의 성공/실패를 나중에 값으로 표현하는 객체(`pending → fulfilled/rejected`).
- **async / await** — Promise를 동기 코드처럼 쓰게 해주는 문법 설탕. `await`는 마이크로태스크로 이어진다.

## 면접 포인트

- **Q. JS는 싱글 스레드인데 어떻게 비동기가 가능한가?**
  → 실행은 싱글 스레드지만, 타이머·네트워크 같은 작업은 브라우저(Web API)/런타임이 대신 처리하고, 완료되면 콜백을 큐에 넣는다. 이벤트 루프가 스택이 빌 때 이를 실행한다.
- **Q. `setTimeout(0)`과 `Promise.then` 중 무엇이 먼저 실행되나?**
  → Promise(마이크로태스크)가 먼저. 한 태스크가 끝날 때마다 마이크로태스크 큐를 **전부** 비운 뒤 다음 매크로태스크로 넘어간다.
- **Q. `await` 다음 코드는 언제 실행되나?**
  → `await` 지점에서 함수가 일시 중단되고, 나머지는 마이크로태스크로 예약되어 콜 스택이 빈 뒤 재개된다.

## 목표

- 동기 코드 + `setTimeout` + `Promise`가 섞인 코드의 출력 순서를 예측할 수 있다.
